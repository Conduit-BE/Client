# Bedrock 1.26.63.1 compatibility profile

On 2026-11-12, LeviLauncher installed the Windows GDK x64 release listed as
`1.26.63.01`. The game PE version resource reports `1.26.63.1`.

The investigation compared the native reload, diagnostics, and title-logo
interfaces with [1.26.62.1](1.26.62-compatibility-profile.md). Use the PE
unwind records to bound the functions in the 1.26.62.1 profile. Disassemble
with Capstone and compare full instruction sequences after masking
RIP-relative displacements and relative call and branch operands. Locate
vtables by matching several function pointers at the same slot offsets.
Resolve the scene name getter through the scene stack table at slot `+0x128`.

The compared native function bodies matched after masking, and the mapped
vtables retained their slot layouts. The UI callback moved to `0xf20000`,
the renderer view entry to `0x4cb3190`, and the primary screen-name caller
returns to `0x65b0a79`. The component constructors still reference the factory
and binding masks at `0x128f7dc8` and `0x128f7e28`. These addresses apply to
1.26.63.1.

The source profile reuses the layouts and hook signatures from 1.26.62.1.
In the isolated 1.26.63.01 instance, Conduit drew the title logo and logged
a complete sample of the title screen's controls, factories and bindings.
Ctrl+R dispatched the native callback and the completion hook returned on
the game thread. F3 produced a live diagnostics snapshot. To verify visible
pack changes, edit an active JSON UI pack, reload, and reopen the affected
screen. Ctrl+K hook retirement also remains to be checked on this build.
