# Legacy UI hover inspection

On 2026-11-13, the local Windows GDK x64 executables reported file versions
`1.26.60.5`, `1.26.62.1`, and `1.26.63.1`. Compare the functions below using PE
unwind bounds and Capstone, masking relative branch and RIP-relative operands.
The matched function bodies preserve the field accesses across these builds.

In 1.26.60.5, `0x1c68360` computes cached absolute position at control `+0x10`
and clears dirty bit 0 in `+0x18`. The native containment check in
`0x1c52140` adds the size at `+0x48` to that position. The traversal at
`0x4c6dd90` adds the control's layer at `+0x68` to the inherited layer,
propagates visibility from bits `0x0c` at `+0x18`, and visits children in
vector order. The corresponding traversal addresses are `0x4c6df60` on
1.26.62.1 and `0x4c6dcc0` on 1.26.63.1.

Conduit reads the active legacy view on its render thread and uses this layer
and tree order to choose a visible control. Its highlight represents the
control's layout bounds. Type labels identify recognized runtime components.
The original JSON type string has not been recovered from every live control.

Press F5 on the title screen and hover across buttons and the logo. Compare
the highlight to their bounds and check that pressing F5 again hides it.
