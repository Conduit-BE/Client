# Bedrock 1.26.62.1 compatibility profile

On 2026-11-12, LeviLauncher installed the Windows GDK x64 release listed as
`1.26.62.01`. The game PE version resource reports `1.26.62.1`. The reference
for comparison was the local LeviLauncher installation of `1.26.60.5`.

The investigation checked whether the existing reload, diagnostics, and title
logo code could use the same layouts with new addresses. Use the PE unwind
table to bound the functions named in the 1.26.60.5 profile. Disassemble them
with Capstone and compare instruction bytes after masking RIP-relative
displacements and relative call and branch operands. The compared functions
with unwind records matched over their full lengths. The owner and cache
getters matched as short leaf functions. The scene name getter was resolved
through the verified scene stack vtable slot at `+0x128`.

Match vtables by resolving several of their function pointers at the same
slot offsets in both images. The owner and client tables are at `0xf092b50`
and `0xf2ba330` in 1.26.62.1. The factory and binding constructors reference
component masks at `0x128f7dc8` and `0x128f7e28`. The frame caller returns to
`0x83274`, the screen name caller returns to `0x65b0d19`, and the targeted UI
callback entry is `0xf202a0`. These addresses apply to this profile.

The matching instructions support reusing the object field offsets and
entry signatures. Profile selection uses the AMD64 PE machine and exact
file version. Before hooking, Conduit checks that entry signatures match in
committed executable memory. The reload backend also checks the live owner,
vtable slots, guards, and frame affinity before dispatch.

On the test instance, the rebuilt DLL drew the title logo, sampled the start
screen's controls, factories and bindings, and produced an F3 diagnostics
snapshot. Ctrl+R queued and dispatched the native callback, and the completion
hook returned on the game thread. A visible resource-pack edit and Ctrl+K
deactivation were outside this run's verification.

To validate in game, start an isolated 1.26.62.01 instance with the standalone
DLL. Check the startup log, open F3, change screens, press Ctrl+R after editing
a mounted development pack, and confirm the visible change and completion
log. Press Ctrl+K and confirm hook retirement in the startup log.
