# ConduitClient v0.4.2-beta — Diagnostics settings

Experimental Windows x64 pre-release for the exact Minecraft Bedrock GDK **1.26.60.5**, package **1.26.6005.0**. Unknown executable images remain unsupported.

## Changes

Add these startup settings to `%LOCALAPPDATA%/ConduitClient/config.json`:

```json
{
  "diagnostics": {
    "scale": 1.0,
    "factories": {
      "enabled": true,
      "empty": true
    }
  }
}
```

- `scale` changes native overlay text measurement, rendering, spacing and padding together. Default `1.0` uses native font scale; `0.7` approximates the previous smaller overlay. Valid range: 0.25–4.0. Minecraft GUI scaling still applies.
- `factories.enabled: false` hides the entire factory section.
- `factories.empty: false` hides rows only when both controls and live roots are zero. Sampling and diagnostic logging remain active.
- Missing fields receive defaults and unknown fields survive migration. Invalid types/ranges fail startup with a logged error while preserving the original config.
- README, configuration and installation documentation are updated. Existing targeted Ctrl+R reload, F3 metrics, title-logo rendering and safe deactivation are retained.

## Installation and limitations

Restart Minecraft before injection, especially if a previous DLL was loaded. Inject only one standalone client. Settings are read at startup; restart and reinject after editing. Download `ConduitClient.dll`, `SHA256SUMS`, `LICENSE` and `THIRD_PARTY_NOTICES.txt` from this release. No external PNG or resource-pack installation is required.

Ctrl+K performs safe deactivation; physical DLL unloading remains unimplemented and native references stay pinned until process exit. The title-logo guard remains conservative. See [configuration](../configuration.md) and [logo verification limits](../title-logo-fix.md).
