# Conduit Client v1.0.0-stable

- Configure the diagnostics, tooltip, reload, and eject shortcuts in `config.json`. The active reload shortcut applies settings and reloads Minecraft’s JSON UI.
- Adjust both overlays with `ui.scale` and `ui.alpha`. Text stays opaque, and existing `ui_scale` values migrate on startup.
- The main-menu logo requests a fresh texture after a world transition.
- After the eject shortcut retires its hooks, reinject from the same DLL path using a LoadLibrary-based injector. Restart Minecraft once when upgrading from an older pinned build.

Supported Bedrock GDK x64 builds are 1.26.60.5, 1.26.62.1, and 1.26.63.1. The Windows x64 DLL built successfully and all 11 portable tests passed. In-game reinjection remains unverified.

See the [configuration guide](../configuration.md) and [standalone installation guide](../standalone-initialization.md).
