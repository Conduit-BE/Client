# ConduitClient v0.6.1 — F5 control types

- F5 displays the resolved JSON UI type used to build a legacy control. This covers types such as `stack_panel` alongside `button`, `image`, `label`, `panel`, and `custom`.
- When injecting into a running game, reopen the screen or use Ctrl+R to rebuild controls that were created before injection. Unobserved controls show `unknown`.

Live verification on Bedrock 1.26.60.5 under Proton confirmed the labels on the title and Pause screens after Ctrl+R, including `stack_panel`. The 1.26.62.1 and 1.26.63.1 profiles also require the type-capture signatures to match at runtime.
