# ConduitClient v0.6.0-beta — UI hover inspector

Press **F5** to toggle the inspector. Hover over a legacy UI control to highlight its bounds in translucent light blue and see its name, runtime type, layer, size, position, visibility, and parent chain. The tooltip lists up to six ancestors, starting with the immediate parent. Unrecognized runtime types appear as `control`.

Set `ui_scale` at the top level of `config.json` to resize both the **F3** diagnostics and **F5** tooltip. Existing `diagnostics.scale` values migrate automatically. Restart Minecraft to apply changes.

Use the standalone `ConduitClient.dll` with Bedrock GDK x64 **1.26.60.5**, **1.26.62.1**, or **1.26.63.1**. Verify the download against `SHA256SUMS`. See the [installation guide and keybinds](../standalone-initialization.md).

The Windows release build passed eight targeted tests. Windows Application Control blocked the standalone policy test executable from starting.
