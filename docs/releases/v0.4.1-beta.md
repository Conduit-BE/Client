# ConduitClient v0.4.1-beta — Title logo fix

2026-11-09. Experimental Windows x64 pre-release for Minecraft Bedrock GDK **1.26.60.5** (package **1.26.6005.0**) only. Unknown executable images remain unsupported.

## Changes

- Fixes the missing title-logo renderer in v0.4.0-beta. The embedded ConduitClient PNG is imported through Minecraft's native texture loader and rendered in the original title image bounds with its aspect ratio preserved.
- Restricts replacement to the verified active main-title scene, vanilla title control and texture. A conservative global-pack metadata check retains original rendering for customized or unidentified profiles. No global texture override, resource pack installation or game-file edit is used.
- Materializes the embedded PNG in `%LOCALAPPDATA%/ConduitClient/cache/`; missing or damaged cached data is repaired safely. Diagnostic logs remain under `logs/`.
- Preserves the website-edited README and updates installation, version and feature documentation.
- Retains targeted Ctrl+R reload, F3 diagnostics and safe Ctrl+K deactivation.

## Verification and limitations

Portable tests: **11/11 passed**. Windows/Wine tests: **24/24 passed**. The release standalone DLL builds successfully. A compiled experimental build of the same logo implementation was visually checked in the running game after Frida detached; the correct ConduitClient image appeared on the title screen. The release version bump itself has not been reinjected.

World/loading/pause screens, custom-pack transitions, repeated Ctrl+R, F3 and deactivation still require normal in-game regression verification. Automated synthetic-host tests do not prove native game behavior. The metadata guard is conservative and periodically refreshed; it is not proof of native resource-pack provenance. See [implementation and evidence](../title-logo-fix.md).

Ctrl+K **deactivates** the client; physical DLL unloading remains unsafe and is not implemented. The module, trampolines and imported native logo references remain pinned until Minecraft exits, avoiding dangling deferred rendering references.

## Installation

Restart Minecraft before injecting this DLL, especially after an earlier client was loaded. Inject only one standalone client into the exact supported build. Download `ConduitClient.dll`, `SHA256SUMS`, `LICENSE` and `THIRD_PARTY_NOTICES.txt` from this pre-release. No external PNG is needed.
