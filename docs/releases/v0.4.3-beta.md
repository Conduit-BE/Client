# ConduitClient v0.4.3-beta — Ctrl+R hotfix

Experimental Windows x64 pre-release for the exact Minecraft Bedrock GDK **1.26.60.5**, package **1.26.6005.0**. Unknown executable images remain unsupported.

## Fixed

Ctrl+R was detected but rejected before native dispatch because disk preflight treated every resource-pack JSON file as a UI object. Valid language arrays such as `texts/languages.json` therefore blocked reload.

- Remove standalone disk JSON preflight. Ctrl+R now dispatches Minecraft's targeted JSON UI reload directly for its mounted definitions. Unrelated files, inactive packs and disk parsing errors no longer block the shortcut.
- Keep executable compatibility, context/thread-affinity checks, request serialization, completion tracking and shutdown guards. This does not restore broad resource reload.
- Clarify reload admission logs and remove blank error messages from custom admission rejection.
- Add regression coverage with a language array and malformed unrelated JSON while verifying dispatch and worker shutdown.
- Retain diagnostics scale/factory settings, F3 metrics and title-logo rendering. Update README, configuration and installation docs.

## Installation and limitations

Restart Minecraft before injecting the new `ConduitClient.dll`; do not load multiple client versions. Settings remain in `%LOCALAPPDATA%/ConduitClient/config.json`, logs under `logs/`. No external PNG or resource-pack installation is required. Download the DLL, `SHA256SUMS`, `LICENSE` and `THIRD_PARTY_NOTICES.txt` from this release.

Minecraft owns native definition parsing and error handling. Removing preflight does not promise rollback or protection from invalid native UI definitions. Ctrl+K remains safe deactivation, with the DLL pinned until process exit. See [configuration](../configuration.md) and [existing logo verification limits](../title-logo-fix.md).
