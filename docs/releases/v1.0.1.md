# Conduit Client v1.0.1

- Add Windows GDK x64 support for Minecraft Bedrock 1.26.65.1.

Supported builds are 1.26.60.5, 1.26.62.1, 1.26.63.1, and 1.26.65.1.
On 1.26.65.1, Conduit initialized in the running game, rendered the title
logo, sampled the title screen controls, and armed the JSON UI reload hook.
Visible resource-pack changes after reload remain unverified.

Download `ConduitClient.dll` from the release assets. Restart Minecraft
or retire the existing Conduit hooks before loading the new DLL.
