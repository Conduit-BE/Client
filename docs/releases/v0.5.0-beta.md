# ConduitClient v0.5.0-beta — Bedrock 1.26.62 and 1.26.63

Adds support for Bedrock **1.26.62.1** and **1.26.63.1** on Windows GDK x64. LeviLauncher lists these builds as **1.26.62.01** and **1.26.63.01**. **1.26.60.5** remains supported.

Conduit now selects a native profile by executable file version and architecture. It checks native instruction signatures before installing hooks. Launcher patches can load when they preserve the expected native code. The release DLL still has a download checksum in `SHA256SUMS`.

In LeviLauncher, import the standalone `ConduitClient.dll` as a `preload-native` mod for a supported GDK instance and restart Minecraft. See the [standalone installation guide](../standalone-initialization.md).

On both new builds, the development DLL rendered the Conduit title logo, produced live F3 diagnostics, and completed the native Ctrl+R callback. Visible resource-pack edits and Ctrl+K deactivation remain unverified on the new builds. See the [1.26.62](../reverse-engineering/1.26.62-compatibility-profile.md) and [1.26.63](../reverse-engineering/1.26.63-compatibility-profile.md) compatibility notes.

The Windows release build passed all seven targeted compatibility and standalone tests.
