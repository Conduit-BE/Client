# ConduitClient v0.1.0-beta.1 — Standalone Experimental Reload

First beta packaging of the standalone Windows x64 DLL for **Minecraft Bedrock Windows 1.26.60.5 / package 1.26.6005.0**, developed through BedrockOnLinux/Proton.

## Changes
- Automatic initialization after DLL injection, outside loader lock.
- Automatic game-thread/live-owner acquisition through the verified V5 frame path; no Frida server, external controller, process/thread configuration or manual activation required by the DLL.
- Preserves V5’s broad native resource reload at RVA 0x873a20.
- Ctrl+R validates JSON before dispatch; continuous resource-pack watching and startup JSON scans are disabled.
- Persistent pack-path configuration, diagnostic logs and safe disabling through a DISABLE file.
- Exact-image, vtable/context checks, request serialization and timeout protection retained.

## Important verification status
**Standalone in-game visual confirmation is still pending.** Published at the user’s explicit request before that confirmation. The earlier Frida-initialized V5 reload was visually confirmed; this beta’s automatic initialization has automated coverage but must still be tested in Minecraft. Do not interpret the beta label as a stability guarantee.

## Setup
Download `ConduitClient.dll`, `SHA256SUMS`, and `THIRD_PARTY_NOTICES.txt`. Follow [configuration, injection, logs and disabling](https://github.com/zelisce/Conduit-Client/blob/v0.1.0-beta.1/docs/standalone-initialization.md). Set the absolute active resource-pack root in `%LOCALAPPDATA%\ConduitClient\config.json`. Inject only this DLL in a fresh Minecraft process; older pinned prototypes require a restart. No resource pack or game executable is modified by installation.

## Known limitations
- Broad resource reload, **not JSON UI-only**; chunk rendering may refresh.
- Roughly one-second freezes may occur and player skins may become invisible.
- Only the exact tested Minecraft image is supported.
- Re-enabling after disable or initialization failure requires a game restart.

**Experimental beta: back up your worlds and use at your own risk.**
