# ConduitClient v0.2.0-beta — Legacy JSON UI Reload

Standalone Windows x64 developer DLL for **Minecraft Bedrock Windows 1.26.60.5 / package 1.26.6005.0**, developed and tested through BedrockOnLinux/Proton.

## New in this beta
- Targeted native legacy JSON UI reload with Ctrl+R, including loading, task synchronization and collection invalidation.
- The user confirmed edited UI appears without visible chunk/texture refresh and confirmed follow-up testing.
- Automatic initialization and current game-thread/owner discovery; no Frida server, controller or manual activation during normal use.
- On-demand JSONC validation. Continuous watching and startup JSON scans remain disabled.
- Preserved `FullResourceReload` V5 fallback, exact-image/context guards, request serialization and safe disabling.

## Installation / upgrading
Download `ConduitClient.dll`, `SHA256SUMS` and `THIRD_PARTY_NOTICES.txt`, verify the checksum and follow [the standalone setup guide](https://github.com/zelisce/Conduit-Client/blob/v0.2.0-beta/docs/standalone-initialization.md).

**Add `"reloadMode": "LegacyJsonUiOnly"` to `%LOCALAPPDATA%\ConduitClient\config.json` alongside the active resource-pack root.** Omitting this field retains the broad resource-reload compatibility default. Existing configs are not migrated automatically.

Inject only this DLL in a fresh Minecraft process. Save a UI edit, press Ctrl+R and reopen the affected screen; normal subsequent edits need no game/world restart or `/reload all`. Create `%LOCALAPPDATA%\ConduitClient\DISABLE` to stop further requests and retire hooks; do not force-unload the pinned DLL.

## Limitations
- A brief pause remains. Four recorded native action durations were 261–357 ms; these are not measured frame stalls or a controlled performance comparison.
- Exact tested Minecraft image only; one client context is supported. Split-screen/multiple contexts fail closed.
- Visual observations establish the tested UI behavior, not exhaustive isolation or long-run guarantees. An exact repeat count and individual skin observations were not separately reported.
- JSON syntax validation does not guarantee Minecraft semantic validation or transactional rollback.
- Native work already executing cannot safely be cancelled. Restart after a timeout/fault or to change configuration/re-enable.
- The optional broad fallback still refreshes chunks/unrelated resources and may cause freezes or invisible skins.

**Experimental pre-release: back up your worlds and use at your own risk.**
