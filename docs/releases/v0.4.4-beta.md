# ConduitClient v0.4.4-beta — LeviLauncher support

Windows x64 pre-release for Minecraft Bedrock GDK **1.26.60.5**, package **1.26.6005.0**.

## Fixed

- Accept the exact executable produced by LeviLauncher 1.1.0 for this Bedrock release. The existing BedrockOnLinux executable remains supported. Conduit checks the executable hash and native signatures before installing hooks.
- Wait for the Minecraft window before installing the diagnostics renderer. This fixes F3 initialization when LeviLauncher loads Conduit before the window appears.

## Install

Verify `ConduitClient.dll` against `SHA256SUMS`. In LeviLauncher 1.1.0, import the DLL as a `preload-native` mod in your **1.26.60.05 GDK** instance and restart Minecraft. See the [standalone installation guide](../standalone-initialization.md).

## Verification

On Windows, the rebuilt DLL initialized in LeviLauncher, sampled the active screen and UI counters, and completed the native Ctrl+R callback. After the startup fix, the diagnostics renderer initialized and drew the Conduit title logo. See the [executable checks](../reverse-engineering/1.26.60-levilauncher.md).

Windows CTest passed 19 of 23 tests, including compatibility and standalone initialization. Two keyboard-driven smoke tests failed at the F3 check, and Windows prevented two test executables from starting.
